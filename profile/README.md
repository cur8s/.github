# cur8s - The art of doing Kubernetes well

cur8s (pronounced “curates”) is a play on the word curated and the Kubernetes numeronym k8s.
It reflects the project’s philosophy: a curated, convention-driven Kubernetes platform — not a reinvention of the ecosystem, but a careful composition of the best, most reliable components.

cur8s = Curated Kubernetes.

By embracing boring, standardized tools and clear conventions, Cur8s provides a stable foundation for platform engineering — so teams can focus on delivering value, not rebuilding plumbing.
