# Cur8s

### The art of doing Kubernetes well.

**Cur8s** is a curated, convention-driven Kubernetes platform. It distills the ecosystem to its essential, reliable parts — a composition of proven tools refined into a coherent, reproducible system.

Like a Michelin-star kitchen that turns simple ingredients into extraordinary dishes, Cur8s is built on craft, restraint, and discipline.  
Each component is chosen for its clarity and reliability, then assembled through explicit contracts and consistent conventions.  
The result is a platform that’s deterministic, self-healing, and transparent — Kubernetes done well.

> **Cur8s = Curated Kubernetes.**  
> The good parts, done beautifully.

### Core Principles

- **Curation over complexity** — use less, but use it better.  
- **Convention over configuration** — opinions that accelerate, not constrain.  
- **Explicit contracts** — predictable integration between layers and teams.  
- **Boring by design** — stability is the highest form of innovation.  
- **Headless by intent** — the Kubernetes API *is* the interface.  
- **Composable evolution** — every layer replaceable, every choice deliberate.  
- **Reproducibility by default** — clusters can be rebuilt, audited, and evolved with confidence.  

cur8s (pronounced “curates”) is a play on the word curated and the Kubernetes numeronym k8s.
It reflects the project’s philosophy: a curated, convention-driven Kubernetes platform — not a reinvention of the ecosystem, but a careful composition of the best, most reliable components.

cur8s = Curated Kubernetes.

By embracing boring, standardized tools and clear conventions, Cur8s provides a stable foundation for platform engineering — so teams can focus on delivering value, not rebuilding plumbing.
